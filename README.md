# Asset Tracker Buddy

A csatolt excel táblázat egy technikai eszközök adatainak nyilvántartására szolgál.







Az adatokat Januártól decemberig göngyölíti.







Technikai eszközök okmányainak száma, "felhasználás" (kilóméter/üzemóra) és üzemanyag. Továbbá, túlfogyasztás/megtakarítás.







Rögzíteni hivatott még a vizsgák és okmányok hitelességének időtartamát (műszaki vagy fő vizsgák), de ez jelenleg nem használt, viszont szeretném dátumra pontosan megadni majd, valamint előrejelzést, ha lejáróban van, legalább egy hónappal a lejárat elött.















Egy ilyen appot szeretnék amely kompakt, és minden fontos információt látni lehet, valamint hozzá adni havi szintre lebontva.
